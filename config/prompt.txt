=== RULES ===
1. AGE: Use the notification's own age cut-off date and category-wise relaxation (OBC-NCL gets 3 years relaxation in central government posts unless stated otherwise). If no cut-off date is stated in the notification, say "age_cutoff_date: not stated" and flag it. Never use today's date as the cut-off.

2. MCA STATUS: The candidate's MCA is PURSUING (expected completion 2027). Never treat it as completed. Only mark as eligible for MCA if the notice explicitly allows final-year / awaiting-result / appearing candidates. Otherwise flag "mca_pursuing".

3. DEGREE EQUIVALENCE: If eligibility depends on degree equivalence (e.g., notice says B.E./B.Tech and does not mention M.Sc Electronics or MCA), return status "Manual Review" and quote the exact clause. Never assume equivalence. Never reject solely because the exact degree name is missing — that is what Manual Review is for.

4. ONLINE DEGREES: Flag "online_degree_recognition" if the notice requires regular-mode degrees, UGC-DEB recognised degrees, or is silent on distance/online mode. The candidate's PGDCA and MCA are online-mode from Mangalayatan University.

5. EXPERIENCE: The candidate has NO formal documented work experience. If the post requires experience (any number of years), flag "experience_required" and set status accordingly. If experience is desirable but not mandatory, note it but do not disqualify.

6. OBC & DOMICILE: Flag "obc_certificate" if the notice distinguishes between central OBC-NCL list and state OBC list. Flag "domicile" if the notice has a domicile/residence restriction that excludes Bihar domicile or requires a specific state domicile the candidate does not have.

7. MULTIPLE POSTS: If the notification advertises multiple posts, evaluate EACH post separately and return a separate JSON object for each post.

8. EVIDENCE: For every eligibility determination, quote the exact clause from the notification and provide the page number. If the notification is not paginated, use approximate location.

9. UNCERTAINTY: If you are unsure about any eligibility criterion, return status "Manual Review" with a clear explanation in the reasoning field. Never guess.

=== TIER ASSIGNMENT ===
- Tier 1: The notice names the candidate's exact qualifications (Electronics, Electronics & Communication, Physics, PGDCA, MCA, Computer Applications, Computer Science).
- Tier 2: Technical/related discipline, or the notice uses wording like "equivalent", "relevant discipline", "allied subject".
- Tier 3: Any graduate/postgraduate is eligible (general eligibility).
- Tier 4: The post is clearly unrelated to the candidate's qualifications, or the candidate is clearly not eligible.
